# Index only core page types

Indexable page types are: home, catalog, family, theme, the terminal target hubs, guides, the editor, and the contribute page. Target-by-theme combinations, hex-value pages, auto-generated comparisons, search results, and port files are not indexed. Similar themes, contrast ratios, and palette deltas live inside theme pages instead.

## Consequences

- Roughly 340 pages at launch (about 170 per locale), each backed by unique palette data, ports, and provenance.
- Long-tail comparison queries are served by on-page data and a client-side comparison tool rather than thin generated pages.
- Curated comparison pages can be added later, but only as editorial pages with unique analysis, not as a combinatorial matrix.
