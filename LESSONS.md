# Lessons from merged work

Read this before changing a documented subsystem. Each lesson is a rule, why it exists, and the evidence that paid for it.

## Check the application, not the category

**Rule:** When a preview claims to represent a terminal, use that terminal's official screenshot or run the app. Do not reuse another app's chrome and change the title.

**Why:** A generic macOS shell labeled “Windows Terminal” is visually false, and users install from the same page the preview appears on.

**Evidence:** The first terminal preview generator used one shared shell for Ghostty, Alacritty, Kitty, iTerm2, and Windows Terminal. The Windows page showed macOS traffic lights and no Windows title bar.

## SVG text does not wrap

**Rule:** Measure labels in the rendered SVG at desktop and 390px. Split or shorten text; do not rely on CSS wrapping inside an SVG.

**Why:** SVG text keeps its width. A color name plus hex code that fits at 1200px can leave the cell at 390px.

**Evidence:** Palette cells in the terminal theme page overflowed their grid on mobile until the name and hex code were stacked and the column count reduced.

## Every target count is a future bug

**Rule:** Derive public counts from `targets` and `ports` where possible. When a count is necessarily literal, update it in the same commit that changes the list.

**Why:** The README, home page, terminal index, `llms.txt`, and several descriptions each carried “six terminals”.

**Evidence:** Adding a target requires edits in more than one public surface; missing one produces copy that contradicts the catalog.

## Verify the built page, not only the component

**Rule:** Run the static build, serve `dist/`, and open the actual route. Check canonical, structured data, and console/runtime output where relevant.

**Why:** Most of this site is generated by catch-all routes. A correct component can still appear on the wrong URL, with stale metadata, or without a sitemap entry.

**Evidence:** Route and SEO checks are part of CI and the manual acceptance pass because the page count and canonical set are generated, not authored.
