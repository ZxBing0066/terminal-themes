# 制作并提交终端主题

目录接受每个主题一个 JSON 文件。你不需要改站点代码，也不需要本地构建。

## 1. 从编辑器开始

打开[编辑器](/zh/editor/)，选择一个已有主题作为起点，调整 16 个 ANSI 颜色以及背景、前景、光标和选区。预览会实时更新，对比度面板会标出过弱的组合。

## 2. 命名文件

使用 kebab-case 的 `family` 和 `slug`。文件路径是 `themes/<family>/<slug>.json`，主题 id 是 `<family>/<slug>`。

## 3. 提交 Pull Request

在编辑器里点击 **Submit**。它会复制主题 JSON，并打开 GitHub 的新建文件页，路径已经填好。粘贴 JSON、提交，然后开 PR。

GitHub 无法可靠地通过 URL 预填文件内容，所以复制粘贴是刻意保留的步骤。

## 4. CI 会检查什么

- JSON 符合 schema。
- 22 个颜色都是 `#rrggbb`。
- 调色板没有和已有主题重复。
- 来源、作者和许可齐全。
- 站点能完整构建，包括预览和导出。

## 5. 审核

维护者会检查来源、命名和中文描述。不要提交上游文件、截图或抄来的文案；颜色值就够了。

## 要求

- 每个 PR 只提交一个主题。
- 不提交外部图片。
- 未知许可标记为 `unknown`，并链接到上游项目。
